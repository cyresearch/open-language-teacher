# 运行手册 · protocol

> 这份文件说明系统「机械层」怎么运转（借鉴 OpenClaw 的 AGENTS.md），
> 并提供一个你可以自由加料的「追加ルール」区。
> 用法：复制到 `config/protocol.md`。**只有「## 追加ルール」之后的内容会进老师的提示词**，
> 之前的部分纯粹是给你看的说明书。

## 系统如何运转（说明，不进提示词）

- **老师每句话前读什么**：`teacher.md`（人设）→ `student.md`（你的画像）→
  `curriculum.md`（教材进度）→ 本文件的追加ルール。改任何一份，下一句话生效
- **◆メモ 协议**：老师每次回复分两段——先是要朗读的口语正文（禁 emoji/记号/markdown），
  然后一行「◆メモ」，其下是用你母语写的课堂笔记（生词/语法点/纠错/话题）。
  引擎按这个标记拆分：正文→合成语音，笔记→写进 `lessons/`
- **课堂记忆**：每次对话追加到 `lessons/YYYY-MM-DD-lesson.md`；老师可以用 Read 工具
  回看（比如你问「上次学了什么」）。这就是她的长期记忆
- **会话记忆**：claude-code 通道靠 `--continue` 延续上下文；api/ollama 通道靠
  `runtime/` 里的滚动历史（默认保留最近 40 条）
- **值班员的账本**：`runtime/duty_state.json` 记着处理到哪条消息；办完一件才记一件账，
  同一条连败 3 次才跳过并明说
