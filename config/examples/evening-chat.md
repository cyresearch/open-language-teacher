# 晚间夜谈 · 配置

> 设计理念：不布置作业，用**每晚定时的温柔夜谈**代替——老师主动来问你今天做了什么，
> 引导你用学习语言讲述自己的一天。这是「让口语练习自然发生」的机制。
> 用法：复制到 `config/evening-chat.md`。触发时间在 deploy 的定时器里改（默认 21:00）。

## 规则

- 每晚定时，老师在 Discord **主动开场**：温柔地问学生今天做了什么
- 目标：引导学生用学习语言讲述自己的一天 → 自然练口语、一点点攒词汇
- 展开：顺着回答追问细节；学生卡壳说不出的词，教对应说法并记进◆メモ；一次只教一个点
- 收尾：聊到自然结束就道晚安；**不催促、不查岗**——当晚没回就算了，第二天照常
- 周日晚：开场换成一周小复盘（轻轻回顾本周 2-3 个生词 + 夸具体的进步）

## 实现

- 定时器每晚触发 `engine/nightly.py`（macOS 用 launchd，模板见 deploy/launchd/）
- 开场白不是固定台词——老师带着课堂记忆现场想（比如接着昨天聊过的话题问）
